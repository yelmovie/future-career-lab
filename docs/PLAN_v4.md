# 미래 직업실 v4 — "3초 안에 뭘 누를지" 재설계 계획 (2026-09-05)

사용자 요구: 상호작용 다양성은 유지하되 미션 해결이 너무 복잡하다. 글 정보 대신 그림·흐름으로 이해하고 **다음에 누를 곳을 3초 안에** 알게. 드론 촬영(S1-a)은 그대로. 클릭만 남기지 말 것. 디자인은 3/10 — 투명 배경 에셋 활용, 버튼 겹침 없이, 가로 태블릿·웹·전자칠판 뒷자리 가독.

## 원칙 (모든 화면 공통)

1. **한 화면 = 한 행동.** 지시문은 한 문장(20자 안팎) 상단 한 줄. 설명 문단 없음. 규칙은 `?` 버튼 안.
2. **큰 그림 버튼.** 텍스트 목록·체크박스 대신 그림 카드(≥120px). 선택지 3개 이하.
3. **단계는 3개 이하**, 상단 점(●○○)으로 표시. 한 단계 끝나면 우하단 큰 노란 버튼만 켜진다. 버튼 위치는 전 화면 동일.
4. **멘토 컷아웃**이 좌하단에서 말풍선 한 줄(질문형). 정답을 말하지 않는다.
5. **실패 = 반응 + 재시도.** 게이지 감소·벌칙 없음. 틀린 카드는 튕기고 한 줄 질문.
6. 글자: 지시 26px, 카드 제목 22px, 보조 18px, 하한 16px. 카드 안 글자 2줄 이내.
7. 좌측 미션 패널·우측 기록 패널을 없애고 중앙 무대 하나. 필요한 상태(배터리·별·게이지)는 상단 오른쪽 칩 하나.
