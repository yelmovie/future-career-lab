# 미래 직업실 제작기

> 이 문서는 초기 버전의 개발 기록입니다. 현재 화면·배포 기능은 [2026-09-12 고도화 기록](releases/2026-09-12-advancement.md)을 참고하세요. 삭제된 입력·시험·자료 준비 기능을 현행 기능으로 안내하지 않습니다.

초등 5~6학년 진로 체험 게임 「미래 직업실」을 만든 과정을 정리했어요. 코드에 실제로 들어 있는 내용만 적었고, 아직 계획 단계인 것은 따로 표시했어요.

## 왜 만들었나

진로교육 자료의 많은 수가 "설문 → 유형 → 추천 직업" 구조예요. 학생은 문항에 답하고 결과지를 받지만, 그 직업이 실제로 어떤 **판단**을 하는 일인지는 겪어 보지 못해요. 결과지가 학생을 단정해 버리는 것도 마음에 걸렸어요.

그래서 방향을 바꿨어요. 유형 검사를 없애고, **사건 하나**를 네 직업의 도구로 차례로 다루게 했어요.

> 도시 옆 숲에서 앵무새가 한 달 사이 절반으로 줄었다. 드론 현장가 → 동물돌봄 전문가 → 생태연구가 → 미래방송기술자가 되어 원인을 밝히고, 마지막에 넷을 한 팀으로 묶어 숲을 되돌린다.

직업 "이름"이 아니라 직업의 **판단 방식**(제약 속 계획, 관찰 → 기록, 변인 통제, 정보 출처 판단)을 학생이 직접 수행하는 게 목표예요.

## 설계 원칙

1. **앞 스테이지 산출물이 뒤 스테이지 재료가 돼요.** 드론으로 찍은 사진 3장이 증거판에 올라오고, 돌봄 기록이 회복 공간의 배치 조건이 되고, 생태 조사 그래프가 방송 자막 카드가 되고, 마지막 연합 작전에서는 각 카드의 품질이 효과량으로 나타나요. 저장 데이터의 `artifacts` 필드(`src/shared/types.ts`)가 이 인계를 담당해요.
2. **시간제한 없이 긴장을 만들어요.** 배터리 대 바람, 두 마리의 다른 상태, 예측을 먼저 적고 실행하기, 시청자 신뢰 게이지, 턴마다 번지는 위기처럼 "조건"으로 긴장을 만들었어요. v1의 3분 타이머는 v2에서 큐시트 턴제로 바꿨어요.
3. **실패는 벌칙이 아니라 단서예요.** 목숨도 되돌리기도 없어요. 배터리가 다 닳으면 "어느 구간에서 빨리 닳았지?"와 함께 바람 화살표가 강조되고, 슬라이더 두 개를 같이 움직이려 하면 "두 개를 같이 바꾸면 어느 쪽 때문인지 알 수 있을까?"라는 질문이 나와요.
4. **능력 진술로 끝나요.** 결과 화면은 성향 점수가 아니라 "나는 이제 ___ 할 수 있다" 문장이에요. 6개 후보 중 2개를 고르거나 직접 써서 수료증에 인쇄돼요. 브리핑에서 고른 "잘 맞을 것 같은 직업" 예측과 실제 플레이를 비교하되, 맞았든 틀렸든 둘 다 의미 있다고 안내해요.

## 스테이지별로 학생이 실제로 하는 조작

|---:|---|---|---|

| 5 | 구조된 앵무새 살피기 | 두 마리를 회전·확대 관찰, 울음소리 분류, 개체별 처치 카드 매칭 | careLog |
| 6 | 회복 공간 만들기 (Phaser) | 돌봄 기록에서 생긴 조건에 맞춰 배치 → 행동 예측 → 시뮬 → 별 | habitatStars |
| 7 | 숲 생태 조사 | 지점 A·B·C 핫스팟 흔적 수집(도감), 그래프 읽기, 슬라이더 한 번에 하나만 실험 | traces, graphs |

## 기술 선택 이유

- **React 19 + Phaser 3**: 드래그 경로·물리 배치·홀로그램처럼 캔버스가 필요한 세 장면(P3·P6·P9)만 Phaser로, 나머지는 DOM/CSS로 만들었어요. 카드·표·입력은 DOM이 접근성과 한글 줄바꿈에 유리해요.
- **localStorage**: 학생 기록은 서버로 보내지 않고 기기에만 남겨요. 앱 안에도 "기록은 이 기기에만 저장돼요"라고 표시해요. 세션 시드로 바람 구간 같은 무작위 요소를 결정적으로 만들어 이어하기가 어긋나지 않게 했어요.
- **서비스워커**(`public/sw.js`): 정적 자원은 캐시 우선, HTML은 네트워크 우선이에요. 교실 와이파이가 중간에 끊겨도 이미 열어 둔 페이지는 계속 진행돼요.
- **셀프호스팅 폰트**: Jua·Pretendard를 서브셋 woff2로 동봉해 외부 요청이 0이에요. 학교망에서 폰트 CDN이 막혀도 화면이 바뀌지 않아요.

## 에셋 제작

- 배경·캐릭터·오브젝트와 v2 추가 이미지 14장(사진 3, 아픈 앵무 2, 흔적 4, 배지 2, 장면 2, 리포터 1)은 생성형 AI로 만든 자체 자산이에요. 프롬프트는 `docs/IMAGEN_PROMPTS_v2.md`에 남겼어요.
- 효과음은 Pixabay 8개에 v2에서 Mixkit 4개(앵무 울음 2, 전기톱, 드론 루프)를 더했어요. 모두 표기 의무 없는 라이선스지만 `assets/CREDITS.md`에 출처를 적었어요. BGM 6곡은 자체 제작이에요.
- 새 에셋이 없어도 완주되도록 fallback을 먼저 만들고 에셋은 나중에 끼웠어요.

## 만들며 배운 점 3가지

1. **페이지 번호와 파일 번호를 분리해 두길 잘했어요.** 게임 순서는 `PAGE_META`와 `App.tsx`의 표가 정하고, 파일 이름의 숫자는 v1 에셋 폴더 번호예요. 덕분에 v2에서 드론 비행을 증거판 앞으로 옮기고 페이지를 하나 늘릴 때 파일을 옮기거나 에셋 경로를 바꾸지 않았어요.
2. **스테이지 규칙을 순수 함수로 빼고 테스트를 붙이면 화면과 따로 고칠 수 있어요.** 생태·방송·연합 모델은 `pageXXModel.ts` + vitest로 분리돼 있어요. 생태 실험의 "기준값이 실험마다 바뀌어 누적되는" 오개념도 화면을 건드리지 않고 모델과 테스트만 고쳐 잡았어요.
3. **스스로 만든 것은 스스로 못 봐요.** 태블릿 감사와 독립 비평 에이전트를 따로 돌렸더니 드론을 경로 없이 통과하는 꼼수, 돌봄 화면 첫 줄에 정답이 노출되는 문제, 방송 화면 정답 노출 같은 결함이 나왔어요. 자기확증을 줄이려면 검수는 만든 사람과 다른 눈으로 해야 했어요.
