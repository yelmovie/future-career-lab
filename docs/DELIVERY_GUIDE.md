# 미래 직업실 운영·인수 가이드

갱신: 2026-09-12. 서비스 주소는 `https://16job.vercel.app/`이다. 현재 구현의 실행·업데이트 절차이며, 실기기·아동 검증 결과를 대신하는 인증서가 아니다.

## 인수할 파일과 재현

소스·package.json·package-lock.json·public의 사용 자산·크레딧·문서를 함께 보관한다. 납품 정적 파일은 `npm run verify`로 만든 `dist/`다. 단독 HTML을 파일 탐색기로 여는 방식이 아니라 HTTP(S) 정적 호스팅을 사용한다. 로컬 검수는 `node scripts/probe-offline.mjs`를 사용한다.

빌드에는 `sw.js`, `classroom-assets.json`, `asset-build-report.json`이 생성된다. manifest의 version은 실제 코드·CSS·HTML·미디어와 SW 소스의 해시로 정해진다. 원본 스토리보드·미사용 그림은 로컬 `_unused/`에 보존한다. Git·배포 포함 범위는 `docs/ASSET_LAYOUT.md`를 따른다.

현재 앱의 자산 경로·Vite base·manifest 시작 주소는 루트 배포를 전제로 한다. SW 캐시는 scope를 기준으로 분리되지만 이것만으로 앱 전체의 하위 경로 지원이 끝난 것은 아니다. 업체가 하위 경로를 요구하면 앱 URL·자산 helper·SW 등록·manifest scope를 함께 변경하고 별도 smoke test를 한다.

## 수업 전 준비와 교대

- 같은 학생이 같은 브라우저와 같은 주소를 사용하면 이어하기가 가능하다. Production·Preview·다른 도메인의 기록은 서로 공유되지 않는다.
- 첫 방문은 온라인으로 연다. 첫 화면 뒤 자동으로 다음 활동 자료를 준비한다. 상단 준비 상태는 실제 캐시 완료량이며 별도의 설정 준비 절차는 없다.
- **그림과 소리 준비 완료**가 표시된 버전만 연결 없이 진행할 수 있다. 준비 전에는 미방문 화면·음원·모형이 없을 수 있다. 연결 복구 후 남은 자료부터 이어 받고, 실패 시 상태 버튼에서 다시 시도한다.
- 브라우저 저장 공간 부족·자동 캐시 정리·수동 삭제가 있으면 저장 상태가 달라질 수 있다. 다음 수업 전에 이어하기를 확인한다.
- 다른 학생에게 기기를 넘길 때는 결과를 필요한 방식으로 보관한 뒤 설정의 확인 단계를 거쳐 기록을 초기화한다. 서버에 학급별 학생 명부나 기록을 전송하지 않는다.
- 교사용 해금은 수업 시연 기능이다. 비밀번호가 클라이언트에 있으므로 보안 인증·요금제 제어로 사용하지 않는다.

## 업데이트와 복구

현재 설정에는 새 자료 적용 버튼이 없다. 수업을 마친 뒤 모든 앱 탭을 닫고 같은 서비스 주소를 다시 연다. 기존 설치에서 사용하던 SW가 있는 경우 새 버전 적용은 탭 종료 뒤 확인한다. 시작 화면 파일이 맞지 않으면 앱이 진행 기록을 남겨 둔 채 캐시와 SW만 한 번 정리하고 최신 화면을 자동으로 다시 요청한다. 두 번째 요청도 실패하면 `다시 열기`와 Chrome 열기 안내를 표시한다. 기기의 진행 기록을 지우는 방식으로 업데이트하지 않는다.

빌드 산출물의 바이트와 manifest 해시는 배포 전에 검사한다. 배포 중 새 파일과 이전 파일이 섞인 경우 탭을 닫고 새 버전으로 다시 연다. 서비스워커 파일과 고정 경로 자산은 HTTP 재검증이 가능하도록 설정되어 있다.

문제가 생기면 먼저 기록을 초기화하지 않는다. 다시 열기·동일 주소 확인·연결 복구를 순서대로 확인한다. 저장 손상·이전 버전 이행은 앱의 저장 복구 경로를 사용하며, 인수 시 보관한 테스트 저장본으로 별도 검증한다. 브라우저 자료 삭제는 진행 기록도 지울 수 있음을 운영자가 먼저 알린다.

## 소리 운영

설정에서 전체 음소거와 BGM/효과음 개별 음량을 조절한다. 듣기 실험 중에는 BGM을 정지하고, 단서 소리 중에는 BGM을 낮추며 UI 효과음이 끼어들지 않게 한다. 화면 전환과 탭 숨김에서 이전 단서·효과음을 정리한다. 듣기 실험도 음소거에 즉시 반응한다.

화면 가장자리가 잘리거나 교실 기기의 브라우저 여백이 큰 경우 설정의 `화면` 탭에서 게임 크기를 80·85·90·95·100%로 조절한다. 80·90·100%는 바로 선택할 수 있으며 선택값은 해당 브라우저에 자동 저장된다.

무음 상태의 시각 안내·입력은 유지하지만 소리를 비교하는 활동의 체감 품질은 헤드셋과 실제 학교 스피커에서 따로 점검한다. 음원 Range 요청의 오프라인 처리와 실제 청취 테스트는 서로 다른 검증이다.

## 교사가 관찰할 학습 행동

1. 사진이나 동물 그림에서 보이는 사실과 학생의 짐작을 구분하는가.
2. 같은 장소에서 조건 하나만 바꾼 결과를 비교하고, 첫 결론과 다르면 수정하는가.
3. 화면에 보이는 조사 정보와 맞는 자막을 골라 시청자에게 전달하는가. 조사자료 팝업은 선택 참고 자료다.
4. 잘못 전한 내용을 정정하고 신뢰를 회복하는가.
5. 앞 탐험의 자료를 새 장소의 조건에 맞게 적용하는가.

정원은 물그릇·숨는 집을 휴식 공간, 놀이 줄을 활동 공간에 두고 먹이나무는 두 공간 중 선택할 수 있다. 타당한 두 설계를 비교하고 그 이유를 이야기한다. 돌봄 활동은 전문가의 도움을 구하는 모의 체험이며 실제 진단·투약·강제 급수 지침으로 사용하지 않는다.

## 교육과정 자료 확인 범위

설정의 성취기준은 연계안이다. 과학 두 기준 [6과16-01]·[6과16-02]의 문구는 교육부·17개 시도교육청·한국직업능력연구원이 발행한 [진로연계교육 교사용지도서 2](https://www.krivet.re.kr/kor/sub.do?menuSn=12&pstNo=PB0000000795)의 공식 목차와 대조했다(확인 2026-09-10). [교육부 고시 제2022-33호 안내](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0)에서 각론과 시행 일정을 확인했다.

실과·도덕 문구의 최종 고시 원문 전수 대조와 학교별 지도 계획 확정은 아직 남아 있다. 과학과 개정 시안은 최종 고시와 코드·순서가 다를 수 있으므로 시안을 최종 근거로 쓰지 않는다. 교사가 선택한 실제 수업의 평가 계획과 확장 과제를 함께 확정한다.

## 자산 권리 확인 범위

글꼴·효과음·이미지 출처와 이력은 `docs/CREDITS.md`, 공사장 음원 증빙은 `docs/licenses/construction-audio.json`에 기록한다. Pretendard 두 파일은 프로젝트에 보관되어 있던 Version 1.309 전체 WOFF2 원본과 바이트를 같게 복구했다. `.sub.woff2`는 기존 URL을 유지하기 위한 파일명이며 현재는 자체 서브셋이 아니다. 원본의 저작권·OFL 메타데이터를 보존했다.

v8 이미지와 스토리보드의 상세 입수 기록, 합성 음성 생성 서비스의 생성 당시 이용조건·업체 납품 범위는 권리자가 보완해야 한다. 외부 계약·유료 플랜·별도 허락을 확인했다고 꾸며 적지 않는다. 신규 자료를 더하면 파일명·출처·권리자·조건·가공·확인일을 함께 남긴다.

## 최종 인수 체크

- typecheck·lint·단위 테스트·실사용 자산 검사·production build·E2E 결과를 해당 버전으로 보관한다.
- 실제 학교 태블릿/전자칠판에서 정상·오답·중단·복원·음소거·인쇄·기기 회전·터치/키보드 완주를 확인한다.
- 학교망 최초 화면 3초·5MB 목표를 측정하고 수업 자료 준비 시간은 별도로 기록한다.
- 준비 완료 후 네트워크를 끊고 미방문 화면·그림·첫 3D 모형·저장·이어하기를 확인한다. 화면 접근 검사와 실제 처음부터 끝까지 플레이한 검사는 구분해 기록한다.
- 기존 버전에서 진행한 상태를 새 배포로 이행하고 수업 중 자동 버전 교체가 일어나지 않는지 확인한다.
- 아동 파일럿에서 이해·재미·자발적 재시도·새 사례 전이를 관찰한다. 소규모 사용성 결과를 교육효과의 일반화된 증거로 발표하지 않는다.
- 실제 서비스 URL의 접근 보호 여부, favicon/OG, 시작→진행→저장→새로고침을 확인한다. 고정 서비스 주소는 `https://16job.vercel.app/`다.
