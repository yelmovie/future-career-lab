# 미래 직업실 v2 — 게임 콘셉트 (재설계안)

작성일: 2026-09-04 · 상태: **제안 (미확정)** · 대상: 초등 5~6학년 · 권장 35~40분
제약: 기존 에셋(배경 10장 · 슬롯 이미지 90장 · BGM 6 · SFX 8)만 사용. 코드 미수정.

## 1. 한 줄 콘셉트

> **도시 옆 숲에서 앵무새가 사라지고 있다. 학생은 드론 현장가 → 동물돌봄 전문가 → 생태연구가 → 미래방송기술자가 되어 원인을 밝히고, 마지막에 네 직업을 한 팀으로 묶어 숲과 도시를 함께 구한다.**

기존 v1은 스테이지끼리 이야기가 끊겨 있었다. v2는 **하나의 사건**을 네 직업이 서로 다른 도구로 다루고, 앞 스테이지의 산출물이 뒤 스테이지의 재료가 된다.

## 2. 콘셉트 후보 3개

### A. 「사라진 앵무새 사건」 — 한 사건을 네 직업이 이어 푸는 수사극 (추천)
- 플레이어 역할: 미래 현장 탐험단 신입. 스테이지마다 다른 직업 장비를 받는다.
- 핵심 행동: 촬영·관찰·기록·변인 실험·생방송 판단·직업 배치.
- 반복 루프: 현장 발견 → 도구로 조사 → 증거 획득 → 다음 직업에게 전달.
- 가장 재미있는 순간: 내가 S1에서 찍은 사진이 S2 증거판에 뜨고, S3 그래프가 S4 방송 자막이 되고, S5에서 네 직업이 동시에 움직일 때.
- 학습 결합: 직업 "설명"이 아니라 직업의 **판단 방식**(제약 하 계획 / 관찰 기록 / 변인 통제 / 정보 검증)을 직접 수행.
- 태블릿 이유: 드래그 경로, 실시간 비행, 슬라이더 변인, 시간제한 방송, 상태 저장.
- 구현 난이도: 중. 기존 P3·P4·P5·P6·P7·P8 코드 대부분 재사용.
- 위험: 스토리 연결 데이터(S1 사진 → S2 단서)를 저장에 실어야 함.

### B. 「직업 체험 부스 4곳」 — 독립 미니게임 4개 + 종합
- 역할: 직업 박람회 방문객. 부스마다 별개 미션.
- 핵심 행동: 부스별 미니게임.
- 재미: 부스마다 신선함.
- 학습 결합: 직업별로 분리, 서로 연결 없음.
- 난이도: 하. 위험: v1과 구조 동일 → "내용만 바뀐 문제 5개" RED FLAG.

### C. 「탐험단 운영 시뮬」 — 자원·시간 배분 경영 게임
- 역할: 탐험단 대장. 4직업 대원을 파견해 하루 일정을 굴린다.
- 핵심 행동: 스케줄링·자원 배분.
- 재미: 최적화.
- 학습 결합: 직업의 실제 작업을 학생이 직접 하지 않는다 → 체험이 아니라 관리.
- 난이도: 중. 위험: 5~6학년에게 추상적, 직업 체험 목적과 어긋남.

### 채점 (5점 만점)

| 항목 | A | B | C |
|---|---|---|---|
| 게임성 | 4 | 3 | 4 |
| 학습 결합 | 5 | 3 | 2 |
| 직관성 | 4 | 5 | 2 |
| 성장감 | 5 | 2 | 3 |
| 디지털 타당성 | 5 | 4 | 3 |
| 제작 현실성 | 4 | 5 | 3 |
| 합계 | **27** | 22 | 17 |

**A 채택.** B의 "부스마다 조작 방식이 다르다"는 장점은 A의 스테이지별 상호작용 차별화로 흡수한다.

## 3. 플레이어 역할과 세계

- **학생 아바타**(page1.student): 탐험단 신입. 스테이지마다 손에 든 장비가 바뀐다(조종기 → 클립보드 → 태블릿 → 헤드셋 → 홀로그램).
- **멘토**(page1.mentor): 브리핑·힌트·결과 해설. 긴 설명 금지, 행동 직전 2줄.
- **앵무새 2마리**(초록·빨강 이클렉투스): **진행도 마스코트이자 세계 반응**. S2에서 구조되어 회복하고, S3 숲에 다시 등장하고, S5 엔딩에서 무리로 돌아간다.
- **헬퍼 로봇**(page2.slot3): HOME·브리핑에서 규칙 안내.

## 6. Stage 1~5 상세

### 소개 · P2 탐험단 브리핑 (3분)
- 멘토가 회의 테이블에서 사건 제시: "숲의 앵무새가 한 달 새 절반으로 줄었어. 원인을 모르겠어."
- 4직업 카드(page-02 아이콘 4개 재활용: precision→드론, care→돌봄, investigation→생태, quick_response→방송)를 **뒤집어 도구 3개 확인**. 
- 학생 행동: 이름 입력 + "나는 이 직업이 제일 잘 맞을 것 같아" 1개 선택 → 명찰 발급.
- 난타 검사: 예측이므로 정답 없음. 통과 조건은 이름+선택.

### Stage 1 — 발견 · 드론 현장가 (8분, P3+P4)
**직업의 판단 방식: 제약(바람·배터리) 아래 경로를 계획하고 실행한다.**

P3 정찰 비행
1. 바람 센서(page4.wind) 값을 읽는다: 풍향·풍속 3구간 중 하나 랜덤(seed).
2. 지도(page4.map) 위에 waypoint 2~4개 드래그. 촬영 목표 3곳: **벌목지·물길·공사장** (사건 단서 3개).
3. 배터리 게이지. 맞바람 구간은 배터리 2배 소모 → 순서를 잘못 짜면 3곳 못 찍음.
4. 비행 실행 → REC → 결과 리플레이. 찍은 사진 3장이 **증거 카드**로 저장(pageData).
- 오답 처리: 배터리 부족 시 "어느 구간에서 배터리가 빨리 닳았지?" + 바람 화살표 강조 → 재계획. 무작위 배치로는 통과 불가(바람 반영 필수).

P4 현장 증거판
1. 증거판(page3.board)에 S1-a 사진 3장 + CCTV 클립 + 발자국 단서가 올라온다.
2. 학생이 단서와 "관찰 사실" 카드를 선으로 연결 (예: 물길 사진 ↔ "물 흐름이 막혔다").
3. 유효 연결 2개 이상 → **가설 1개 선택** (벌목 / 소음 / 물 부족). 정답 확정 아님 → S3에서 검증.
- 앵무새 반응: 사진 속 숲에 초록 앵무가 작게 보인다 → "아직 남아 있어".

성공 시 변화: 학생 장비 = 조종기. 드론 배지(page8.drone badge) 획득. HOME 허브 노드 1 점등.

### Stage 2 — 적용 · 동물돌봄 전문가 (9분, P5+P6)
**직업의 판단 방식: 관찰 → 기록 → 환경으로 되돌려 준다.**

P5 건강 점검 (기존 유지, 서사만 교체)
- 구조된 앵무 2마리. 깃털·눈·부리·배설물·행동 5영역 관찰 → 근거 있는 기록 4개.
- 두 마리 상태가 다르다(빨강: 탈수, 초록: 스트레스 깃털 뽑기) → 같은 처치를 둘 다에 적용하면 한 마리는 악화. **관찰 없이 통과 불가.**

P6 회복 서식지 설계 (기존 유지)
- 횃대·로프·은신처·먹이퍼즐·물·터널 배치 → 시뮬레이션 → 앵무 행동 관찰 → 재설계.
- S2-a 기록이 조건이 된다: 탈수 개체는 물 접근 거리, 스트레스 개체는 은신처 필수.

성공 시 변화: 앵무 두 마리 회복 애니메이션(깃털 윤기). 돌봄 배지. 장비 = 클립보드.

### Stage 3 — 변수 · 생태연구가 (8분, P7 신규)
**직업의 판단 방식: 흔적을 모으고, 변인을 하나씩 바꿔 가설을 검증한다.**

3막 구성, 한 페이지 안에서 탭 없이 순차 진행.

1. **흔적 수집 (탐색)** — 정글 배경(bg6)에서 hotspot 6곳. 발자국(page3.footprint), 깃털(page9.feather), 소리(page3.recorder 터치하면 새소리/톱소리 재생 [가정: 효과음은 기존 SFX로 대체]), 먹이나무 열매, 물웅덩이(page6.water), 환경 모니터(page7.env — 온도·습도). 조사 지점 A·B·C를 돌며 수집. 
2. **연구 태블릿 (비교)** — page5.tablet 위에 지점별 막대 그래프: 먹이나무 수 / 소음 / 물 / 앵무 흔적 수. 학생이 "앵무 흔적이 가장 적은 지점에서 다른 값 중 뭐가 튀는지" 스스로 읽는다. 정답 표시 없음.
3. **변인 실험 (통제)** — 슬라이더 3개(먹이나무·소음·물). **한 번에 하나만 움직일 수 있다**(변인 통제 규칙을 UI가 강제). 바꿀 때마다 앵무 예상 개체수가 즉시 반응. 3회 실험 후 "주원인 1개 + 보조원인 1개" 확정 → S1-b 가설과 대조.
- 오답: 슬라이더 두 개를 동시에 바꾸려 하면 잠기고 멘토: "두 개를 같이 바꾸면 어느 쪽 때문인지 알 수 있을까?"
- 결과 모델 `[가정]`: 개체수 = 기준 × f(먹이) × g(소음) × h(물), 먹이 가중치가 가장 큼. 실제 생태 수치 아님 → **교육용 단순 모델임을 화면에 표기** `[검증 필요: 이클렉투스 서식 요인 우선순위]`.

성공 시 변화: 연구 노트에 그래프 카드 저장(S4 자막 재료). 생태 배지(page9.compass 엠블럼). 앵무가 정글 배경 나무에 앉아 있음. 장비 = 태블릿.

### Stage 4 — 판단 · 미래방송기술자 (8분, P8 신규)
**직업의 판단 방식: 제한 시간 안에 정확한 정보만 골라 내보내고, 사고를 우선순위로 복구한다.**

- 목표: 숲 위기를 시민에게 알리는 **3분 생방송**(실시간 타이머, 모래시계 page7.hourglass).
- 화면: 대형 스크린(bg9)에 송출 화면, 하단 컨트롤 3열.
  1. **소스 선택**: 드론 영상(S1 사진) / 스튜디오 카메라(page4.cinema) / 현장 리포터(page4.monitor). 장면 요구(예: "지금 원인 설명 중")에 맞는 소스를 고른다.
  2. **자막 넣기**: 카드 6장 중 드래그. 3장은 S3 연구노트에서 온 **근거 있는 그래프**, 3장은 그럴듯하지만 출처 없는 문장("앵무새가 도시로 도망갔대요"). 근거 없는 자막을 내보내면 시청자 신뢰 게이지 하락 + 정정 방송에 시간 소모.
  3. **돌발 사고** (page7.beacon): 마이크 끊김 / 영상 지연 / 잘못된 제보 유입. AP 3으로 우선순위 결정 (Page07 모델 그대로).
- 결과: 시청자 이해도 = 근거 자막 비율 × 사고 복구율. 방송 클립 카드 저장.
- 난타 검사: 아무 자막이나 넣으면 신뢰 게이지가 즉시 떨어져 통과 불가.

성공 시 변화: 방송 배지(page8.technology). 도시 홀로그램(다음 페이지)에 "시민 참여" 노드 점등. 장비 = 헤드셋.

### Stage 5 — 종합 · 연합 작전 (7분, P9)
**앞 4개 스테이지 산출물을 모두 써야 풀린다.**

- 도시 홀로그램(bg8 + page8.city) 위 위기 3개 동시 발생:
  - 🔥 벌목지 화재 확산 → **드론(정찰) + 방송(대피 안내)**
  - 🦜 앵무 무리 이동 경로 위험 → **생태(경로 예측) + 돌봄(임시 보호소)**
  - 👥 시민 오해로 복원 반대 → **방송(근거 방송) + 생태(그래프 제시)**
- 직업 배지 4개(드론·돌봄·생태·방송)를 드래그 배치, 시너지 조합만 위기 게이지 감소. 쿨다운. 
- 각 배지는 해당 스테이지에서 얻은 카드가 "탄약": 드론 사진 3장, 돌봄 기록, 그래프 카드, 방송 클립. 카드가 좋을수록(예: S3에서 주원인을 맞혔으면) 효과 큼 → **앞 스테이지 품질이 마지막에 보인다.**
- 엔딩: 홀로그램 화재 꺼지고 숲 노드 초록으로, 앵무 무리 귀환 연출(page1.parrot-pair), 연합 엠블럼(page8.alliance) 획득.

### 결과 · P10 탐험 돌아보기 / P11 수료증
- P10: P2에서 예측한 직업 vs 실제 플레이 로그(성향 6축) 비교. "예측이 맞았든 틀렸든 둘 다 의미 있다"는 비진단형 문구. 근거 3개는 실제 로그.
- P11: 기존 인쇄 수료증. 배지 5개 도장.

## 7. 학습목표 ↔ 플레이 행동 연결표

| 학습목표 | 스테이지 | 플레이 행동 | 왜 이 행동인가 |
|---|---|---|---|
| 직업은 "이름"이 아니라 "판단 방식"이다 | 전체 | 스테이지마다 다른 도구·규칙 | 각 직업의 핵심 사고를 직접 수행 |
| 제약 조건 아래 계획·실행 | S1 | 바람·배터리 반영 경로 설계 | 무작위 배치로는 실패 |
| 근거로 추론하기 | S1-b, S3 | 증거 선잇기, 그래프 읽기 | 정답 표시 없이 스스로 연결 |
| 관찰→기록→돌봄의 인과 | S2 | 두 개체 차이 관찰 후 다른 처치 | 같은 처치는 한 마리 악화 |
| 변인 통제 (과학 탐구) | S3 | 슬라이더 하나씩만 조작 | UI가 통제 규칙을 강제 |
| 정보의 출처·정확성 판단 | S4 | 근거 있는 자막만 송출 | 출처 없는 자막은 신뢰 하락 |
| 협업은 역할의 조합이다 | S5 | 시너지 짝 배치 | 한 직업만으론 위기 안 줄어듦 |
| 자기 이해는 단정이 아니라 되돌아보기 | P2→P10 | 예측 vs 실제 비교 | 비진단형 성찰 |

## 9. 보상·성장·해금

- 직업 배지 4 + 연합 엠블럼 1 (HOME 허브 + 수료증 도장).
- 스테이지 산출 카드 4종(사진·기록·그래프·클립) → S5 "탄약". 점수 대신 **물건**이 쌓인다.
- 해금: 순차. 단 완료한 스테이지는 재도전 가능하고, 재도전으로 카드 품질을 올리면 S5 결과가 달라진다(재플레이 동기).

## 10. 태블릿이어야 하는 이유 (§9 충족)

드래그(경로·배치·자막) · 실시간 변화(비행·타이머) · 여러 변수 조절(슬라이더) · 즉각 시각 피드백(게이지·개체수) · 소리 비교(S3 녹음) · 상태 저장(카드 인계) · 단계 해금. 7개 충족.

## 11. 2D/3D 판단

**2D(DOM + Phaser) 유지.** 3D가 개념 이해에 필요한 장면 없음. 기존 GLB 슬롯은 그대로 비활성.

## 12. 영상 필요 여부

**불필요.** 인트로는 P2 브리핑 대화 + 정지 키아트로 충분하고, 엔딩은 홀로그램 상태 변화 연출로 대체. 컷신 없음.

## 13. IP·유사성

독자 세계관. 참고 IP 없음. 이클렉투스 앵무는 실제 종이며 상표 아님.

## 15. 자기비평

**강한 점**
1. 한 사건을 관통해 스테이지 산출물이 다음 재료가 된다 — "왜 이걸 하는지"가 자연히 생김.
2. 5스테이지 상호작용이 전부 다르다: 경로 드래그·선잇기·관찰 기록·배치 시뮬·핫스팟+슬라이더·실시간 선택·시너지 배치.
3. 신규 에셋 0개. 신규 페이지는 2개(S3·S4)이고 둘 다 기존 코드 모델 위에 얹는다.

**약한 점**
1. S3 개체수 모델이 과학적으로 얕다 → "단순 모델" 고지 필수.
2. S4는 3분 타이머라 느린 학생이 압박을 느낄 수 있음 → 일시정지·연습 라운드 필요.
3. 카드 인계 데이터를 저장 스키마에 추가해야 하므로 SAVE_SCHEMA_VERSION 2 마이그레이션 필요.

**반드시 개선**
- S5의 시너지 짝이 "정답 외우기"가 되지 않도록, 위기 카드에 **필요한 능력 힌트**(예: "위에서 봐야 한다", "근거가 필요하다")만 주고 배지 이름은 주지 않는다.

> **이 기획의 진짜 게임 행동을 한 문장으로 말하면?**
> "직업마다 다른 도구로 같은 사건의 증거를 모아, 마지막에 네 직업을 조합해 숲을 되살린다."
