# 미래 직업실 기능향상기 — v1(2026-08)에서 v2(2026-09)로

> 이 문서는 초기 버전의 개발 기록입니다. 현재 화면·배포 기능은 [2026-09-12 고도화 기록](releases/2026-09-12-advancement.md)을 참고하세요. 삭제된 입력·시험·자료 준비 기능을 현행 기능으로 안내하지 않습니다.

v1 MVP는 2026-08-15에 커밋됐고, v2 재구성은 2026-09-04 하루 동안 여섯 번의 커밋으로 진행됐어요. 무엇이 왜 바뀌었는지 git 기록과 코드 기준으로 정리했어요.

## v1의 한계

v1은 10페이지, 5스테이지였지만 스테이지끼리 이야기가 끊겨 있었어요. 자기이해(8상황 스와이프) → 직업 미스터리 → 드론 → 앵무새 돌봄 → 실시간 업무(3분 타이머) → 연합 → 직업 DNA 순서라, 각 페이지는 따로 놀았고 앞 페이지의 결과가 뒤에 쓰이지 않았어요. 콘셉트 문서(`docs/GAME_CONCEPT_v2.md`)에서 이 구조를 "내용만 바뀐 문제 5개"라고 스스로 지적했어요.

## 구조: 10 → 11페이지, 스테이지 재편

| | v1 | v2 |
|---|---|---|
| 페이지 수 | 10 | 11 |
| 도입 | 일하는 방식 8상황 스와이프 | 탐험단 브리핑: 사건 접수, 직업 카드 뒤집기, 예측 직업 선택 |
| 스테이지 1 | 자기이해 | 드론 정찰 → 현장 증거판 (드론 현장가) |
| 스테이지 2 | 미스터리 + 드론 | 앵무새 살피기 → 회복 공간 (동물돌봄) |
| 스테이지 3 | 앵무새 돌봄 + 서식지 | 숲 생태 조사 (생태연구가, 신규) |
| 스테이지 4 | 실시간 업무 (타이머) | 생방송 컨트롤룸 (방송기술자, 신규, 타이머 없음) |
| 스테이지 5 | 연합 위기 대응 | 네 직업 연합 작전 (턴제) |
| 결과 | 나의 직업 DNA | 탐험 돌아보기: 예측 vs 실제, 우리 동네 전이, 능력 진술 |

파일은 옮기지 않고 `src/app/App.tsx`의 매핑 표와 `PAGE_META`만 바꿨어요. 그래서 `Page04Drone.tsx`가 3페이지, `Page03Mystery.tsx`가 4페이지를 맡아요. v1의 스와이프 화면은 `_unused/v1-pages/`로 옮겼어요.

## 저장 스키마 v2와 artifacts

`SAVE_SCHEMA_VERSION`을 2로 올리고 `artifacts` 필드를 추가했어요. 사진 3장과 촬영 품질, 가설, 돌봄 기록, 서식지 별, 흔적 도감, 그래프 판정, 방송 클립(신뢰·정정 횟수), 연합 턴 수가 여기 쌓여요. v1 저장 기록은 페이지 번호 체계가 달라 완료 기록을 그대로 옮기면 "산출물 없는 완료"가 생기므로, 이름과 오디오 설정만 남기고 진행은 비워요(`src/state/storage.ts`).

## 새 스테이지 2개

- **숲 생태 조사(7페이지)**: 지점 A·B·C를 오가며 발자국·깃털·소리 흔적을 모아 도감을 채우고, 지점별 그래프에서 튀는 값을 스스로 고른 뒤, 슬라이더 3개를 **한 번에 하나만** 움직여 예측 → 실행 → 대조를 반복해요. 모델은 교육용 단순 함수이고 화면에 그 사실을 표시해요.
- **생방송 컨트롤룸(8페이지)**: v1 실시간 업무의 사고 대응(AP 배분) 모델은 남기고 3분 타이머를 뺐어요. 대신 큐시트 6세그먼트를 턴제로 진행하며 소스 선택, 출처 있는 자막 드래그, 오디오 레벨 조절을 해요. 출처 없는 자막을 내보내면 신뢰가 떨어지고 정정 방송 세그먼트가 끼어들어요.

## 재설계된 스테이지

- **드론**: 촬영 목표를 사건 단서 3곳(벌목지·물길·공사장)으로 바꾸고 REC 타이밍을 넣었어요. 정중앙 촬영 여부가 저장돼 마지막 연합에서 효과량이 돼요.
- **증거판**: 사진 확대 관찰 핫스팟, 확실/의심/무관 3칸 분류, 무관 카드 1장을 더했어요. 사진을 보지 않으면 연결할 수 없어요.
- **앵무새 살피기**: 두 마리 상태가 달라(초록 스트레스, 빨강 탈수) 같은 처치를 둘 다 주면 한 마리가 나빠져요. 울음소리 분류가 추가됐어요.
- **회복 공간**: 돌봄 기록에서 조건이 자동 생성되고(탈수 개체는 물 거리, 스트레스 개체는 은신처), 행동 예측 → 시뮬 → 별 3개 구조가 됐어요.
- **연합 작전**: 위기 카드에 배지 이름 대신 능력 힌트만 주고, 턴마다 확산하는 턴제로 바꿨어요. 앞 스테이지 카드 품질이 효과에 반영돼요.
- **돌아보기**: 예측 직업 비교, "우리 학교 옆 놀이터 공사" 상황에 직업 순서 배열, 능력 문장 선택이 들어갔어요.

## 오프라인 지원

`public/sw.js` 서비스워커와 `manifest.webmanifest`를 추가했어요. 정적 자원은 캐시 우선, HTML은 네트워크 우선, 오디오는 range 요청 문제로 네트워크 우선이에요. `scripts/probe-offline.mjs`로 오프라인 동작을 확인해요.

## 검수

두 갈래로 봤어요.

1. **태블릿 감사** → 홈 화면 접힘 대응, 증거판 연결 열 정리, 수료증 도장 겹침, 아이콘 교체, v1 저장 초기화 등을 반영했어요(커밋 a3854b0).
