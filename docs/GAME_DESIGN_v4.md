# 미래 직업실 v4 — 페이지별 흐름 (구현 기준 문서)

서사는 `docs/GAME_CONCEPT_v3.md` 그대로(모모·루비·푸른솔 숲·하늘숲 동물원 새 정원·사육사 하늘). 이 문서는 **각 화면에서 학생이 무엇을 보고 무엇을 누르는지**만 정한다. 기존 모델 파일(`page05CareModel.ts`, `habitatModel.ts`, `page07EcologyModel.ts`, `page08BroadcastModel.ts`, `page08CrisisModel.ts`, `stage1-2-content.ts`)의 판정 함수·저장 필드(`artifacts.*`, `completePage`, `addBadge`)는 유지하고, 화면과 단계만 줄인다.

공통 화면 틀 = `src/components/v4/StepShell.tsx` (아래 §0). 모든 페이지가 이걸 쓴다.

## 0. StepShell — 공통 화면 틀

```
┌ topbar 60 (기존 GameShell) ──────────────────────────────────────────┐
│ ●○○  [지시 한 문장 26px Jua]                       [상태 칩: 배터리 70%] │
│                                                                          │
│                     중앙 무대 (children, 1000×470 안)                     │
│                                                                          │
│ [멘토 컷아웃 220px]〔말풍선 한 줄〕                    [다음 버튼 노랑 64px] │
└──────────────────────────────────────────────────────────────────────────┘
```
- props: `page`, `step`(1-based), `steps`(총 수), `instruction`, `mentor`(이미지), `bubble`(한 줄), `status?`(칩 텍스트), `next: { label, disabled, hint, onClick }`, `help?`(? 모달 내용), `children`.
- 다음 버튼은 항상 우하단, 비활성이면 회색 + 누르면 `hint` 토스트("사진 3장을 다 보면 켜져요").
- 완료 시 `StageComplete` 대신 StepShell 의 `done` 모드: 무대 위에 큰 도장 애니 + 한 줄 + 다음 버튼.

## 1. P2 브리핑 (3단계)

| 단계 | 화면 | 누르는 것 | 완료 조건 |

| 1 사건 | 모모·루비 그림(parrot-pair) 크게 + 단장 말풍선 대사 1줄 | 말풍선 탭 → 다음 대사 (3줄) | 3줄 다 봄 |
| 2 네 직업 | 직업 캐릭터 컷아웃 4명 가로 나열(드론 page-04/slot-01, 돌봄 page-05/slot-01, 생태 page-07/slot-01, 방송 page-03/slot-03) | 캐릭터 탭 → 말풍선 "나는 하늘에서 찍어!" + 도구 그림 3개 | 4명 다 탭 |

- 끝내면 얻는 것은 `?` 모달로.

## 2. P3 드론 (메커닉 유지, 표면만)
- 지시: 1단계 "바람을 피해 점을 찍어" → 2단계 "비행! 원 안에서 REC" → 3단계 결과.
- 좌측 미션 패널·우측 상태 패널 제거. 배터리는 상단 상태 칩, 촬영 목표 3개는 지도 위 원만.
- 구간 라벨 "1구간 · 화살표 거스르면 맞바람" → 화살표만. 범례는 `?`.
- 결과: 사진 3장 크게 + "증거판으로" 버튼. 실패: "배터리가 어디서 빨리 닳았지?" + 빨간 구간 강조 + "다시 계획".
