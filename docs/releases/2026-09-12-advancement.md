# 미래 직업실 · 현행 제작·기능향상 기록

직업 이름을 외우는 대신 여러 직업이 같은 사건을 어떻게 다루는지 경험한다. 드론 사진은 사육사와 조사 팀에게, 조사 결과는 방송 팀에게, 방송은 함께 일할 사람들에게 이어진다. 학생의 결과물은 사진·돌봄 기록·수정한 결론·직접 만든 방송·팀이 돌본 숲이다.

초기의 연구기록 시험, 억지 오답 자막, 정답과 무관한 그림은 현행 흐름에서 제거했다. 실패는 점수를 깎기 위한 함정 대신 다시 볼 단서를 준다. 사진에서 세운 짐작을 조사 결과에 맞춰 고치고, 정원 배치도 다시 시험한다.

## 이번에 달라진 행동

- 생태 비교 그림 실패에는 재시도와 숫자로 확인하는 경로가 있다. 직접 확인하기 전에는 완료로 올리지 않고, 새로고침마다 시도를 중복 저장하지 않는다.
- 사진의 같은 관찰 지점을 키보드로 찾을 수 있다. 본문 바로가기는 주소를 바꾸지 않으며, 모달은 입력할 때마다 첫 버튼으로 돌아가지 않는다.
- 방송 카드는 짧은 제목과 실제 방송 문장을 나누어 읽는다. 자막 원문·선택 ID·선택 참고 자료·마이크 교체와 방송 재개·내 방송 다시보기는 유지한다.
- 마지막 자막을 내보내면 방송기술자 배지를 먼저 확인하고, `내 방송 이어 보기`로 자신이 고른 네 장면을 재생한다. 이미 끝낸 예전 저장 기록은 다시 들어왔을 때 곧바로 방송을 볼 수 있다.
- 공사 소리를 작게 비교한 뒤 가림벽 또는 큰 기계의 쉬는 시간 중 부탁을 고른다. 선택한 부탁이 결과와 활동 기록에 남는다. 슬라이더 자체가 현실 기계를 원격 조종하는 설정은 아니다.
- 숲을 도운 뒤 원하는 학생만 학교 화단을 더 돕는다. 열매·그늘은 충분하고 물그릇이 비어 있다. 숲에서 쓴 방법을 무조건 반복하면 다른 단서로 다시 살펴본다. 물 주기 버튼을 길게 누르거나 짧게 여러 번 눌러 물을 채우며, 중간 양과 선택 수정이 저장된다. 결과는 사육사·선생님·방송 팀의 계속되는 돌봄으로 이어진다. 추가 시험·연구기록 팝업이 없으며 수료증 해금과 무관하다.

## 그림·성능·운영

큰 PNG 13종을 같은 구도·해상도·투명도의 WebP로 인코딩했다. 원본 28,481,044바이트에서 배포 사본 3,875,014바이트로 줄었고 원본은 `_unused/release-optimization-20260912/`에 보존한다. 학교 화단 전후 그림 두 장은 Codex 내장 imagegen으로 새로 만들고 `public/assets/v10/`에 적용했다. 선택한 OG 3번 그림은 유지했다.

처음 두 모듈은 실제 완료 수로 로딩을 표시한다. 첫 화면 뒤 이후 활동 파일을 자동으로 준비하며 완료 전후를 구분한다. 연결이 끊기면 준비를 멈추고 복구 후 남은 파일부터 이어 받는다. 수업 중 버전을 자동 교체하지 않는다.

개발 서버는 검사 결과 폴더를 감시하지 않는다. Playwright trace HTML이 Vite 새로고침을 유발하고 다시 trace를 만드는 반복을 차단했다.

## 유지보수와 검증 범위

협업 내용은 `cooperationMissions.json`, 학교 화단은 `schoolGarden.json`에서 교체한다. 화면·판정·복원을 나누어 내용과 저장 호환을 따로 검사한다. README의 추가 절차, 운영 가이드, 크레딧을 현재 화면과 맞췄다. 초기 제작기·기능향상기는 과거 버전으로 표시했다.

기능·복구·입력·겹침·캐시·배포 무결성은 코드 검사와 브라우저 실행으로 확인한다. 실제 학생의 재미·이해, 교실 뒷자리 가독성, 학교망 동시 접속, 외부 서비스의 당시 계약 증빙은 별도 확인이다. 개발 검사 통과를 교육효과나 모든 기기의 보증으로 쓰지 않는다. 실행 수치·점수·미확인 항목은 최종점검 보고서에 남긴다.

최신 production 빌드는 189파일·65,668,644바이트, 버전 `ba5e5b5e4c3b42a7`이다. 새 Chromium에서 자료 189개를 준비한 뒤 네트워크를 끊고 홈부터 수료증 저장까지 19/19단계를 통과했다. 이 흐름에는 방송 배지 확인과 네 장면 이어 보기도 포함한다.

수료증 인쇄 미리보기가 빈 종이로 보이던 CSS 충돌도 바로잡았다. 작은 화면 안내는 화면에서만 동작하고, 인쇄에서는 A4 가로 수료증과 배경색·그림을 표시한다. 세로형 print 미디어 뷰포트에서도 게임 셸과 수료증이 숨지 않는 회귀 검사를 추가했다.

원본 PNG 13개는 SHA-256으로 보관본과 일치함을 확인한 뒤 `public/`의 중복 사본을 제거했다. 변환 이력은 `docs/ASSET-OPTIMIZATION-20260912.json`으로 버전 관리한다. 원본이 있는 이 작업 폴더에서는 `scripts/optimize-release-images.py`로 재인코딩할 수 있다. 원본은 이전 Git 커밋에도 남아 있으며, 새 체크아웃에서는 먼저 해당 원본 보관본을 마련해야 한다. 쓰지 않는 예전 `TransferMission`·`HabitatScene` 화면은 `_unused/retired-code-20260912/`로 보관했고 이전 저장 기록의 호환 코드는 유지한다.

배포 경로는 해시 라우터를 사용하므로 모든 주소를 HTML로 바꾸던 규칙을 제거했다. 존재하지 않는 자산은 404로 응답한다. 이미 열어 둔 이전 버전의 그림 요청을 위해, WebP로 교체한 PNG 주소 13개만 새 그림으로 연결하는 호환 규칙을 남겼다. 큰 PNG를 중복 배포하지 않는다.

학교 화단을 완성하면 상단 안내와 말풍선도 완료 내용으로 바뀐다. 최초 화면의 본문 글꼴 선로딩은 제거하고 접근성 전용 숨김 설명에는 시스템 글꼴을 써 로딩 의존성을 줄였다. 학교 활동 완료 뒤 다시 선택하라는 안내가 남지 않도록 확인했다.
