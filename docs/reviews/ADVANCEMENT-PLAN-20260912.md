## 실행 순서

1. **진행 복구**: 생태 비교 원본/대체 그림 실패와 장시간 대기에서 다시 시도 또는 숫자 비교를 직접 확인한다. 중복 시도·기록 소실 없이 새로고침을 복원한다.
2. **동등한 조작**: 본문 바로가기의 해시 이동을 막고, 사진 관찰을 키보드로도 완료한다. 모달 입력마다 초점이 튀는 문제를 없앤다. 1024 태블릿의 조작 영역과 작은/세로 화면 안내를 확인한다.
3. **한눈에 읽는 방송**: 선택 카드의 짧은 제목과 방송될 문장을 구분한다. 원문 자막과 선택 내용은 실제 방송에 그대로 연결한다. 조사자료 열기는 선택 사항으로 유지한다.
4. **선택이 남는 협업**: 공사 소리 비교 뒤 가림벽/작업 휴식 중 전할 부탁을 고른다. 선택은 다른 팀의 행동 설명과 탐험 기록에 남긴다. 소리 슬라이더는 실제 공사장을 원격 조종하는 장치가 아니라 작은 소리를 미리 비교하는 활동이다.
5. **선택형 새 장소 적용**: 숲의 회복을 본 뒤 학교 화단을 더 도울 수 있다. 열매·그늘이 충분하지만 물그릇이 빈 그림에서 필요한 도움을 찾고, 틀린 선택은 관찰 힌트로 고친다. 물 주기를 길게 누르거나 여러 번 눌러 완성하고, 사육사·선생님·방송 팀이 계속 돌보는 후일담을 본다. 추가 시험·연구기록 팝업이 없고, 수료증은 이 활동과 무관하게 열린다.
6. **빠른 그림·연결 복구**: 대형 PNG를 구도·해상도·투명도를 유지한 WebP로 인코딩한다. 원본과 변환 기록을 보존한다. 초기 모듈 진행 표시, 유휴 사전 캐시, 끊긴 연결 복구를 구현한다. 전체 자료를 실제로 캐시한 경우에만 오프라인 준비 완료로 표시한다.
7. **인수 가능한 문서**: 현재 내용 데이터 위치·스테이지 추가 절차·저장/복구·새 에셋 이력·현재 제작기를 정리한다. 폐기 코드와 과거 기록을 현행 기능으로 소개하지 않는다.
8. **검증 후 배포**: lint/typecheck/unit/에셋 무결성/build → 정상·실패·키보드·터치 E2E → 1280×800, 1920×1080, 1024×768, 915×412 및 세로 화면 확인 → production 초기 로딩·오프라인·복구 측정 → 커밋·푸시 → 실제 운영 주소와 OG/저장/새로고침 검증.
