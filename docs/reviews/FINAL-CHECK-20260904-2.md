## 최종 판정: 조건부 배포 가능

핵심 경로, 자동 저장, 이어하기, 완료 후 재방문, 회고, 인증화면 도달에는 `FAIL`이 없다. 1024×768 가로 태블릿에서는 보이는 조작 요소가 모두 실제 48px 이상이며, 작은 화면과 세로 화면에는 축소된 버튼 대신 기기 안내가 표시된다.

다만 1280×720 전자칠판 기준에서 16px 미만으로 지정된 CSS 글자 선언이 159개 남아 있어 12번을 `FAIL`로 판정했다. 핵심 행동 안내와 다음 버튼은 읽고 누를 수 있지만, 교실 뒤쪽 학생이 보조 설명까지 읽는 환경에는 부족하다. 이 문제는 UI 영역의 조건부 예외이며 학습·데이터 안전·핵심 저장 경로의 실패는 아니다.

## 배포 전 처리할 조건

1. 전자칠판 수업을 지원하려면 1280×720에서 실제 보이는 보조 글자를 16px 이상으로 올린다. 화면을 더 빽빽하게 만들지 말고, 각 작업을 한 단계씩 보여 주거나 긴 설명을 상세 패널로 옮기는 방식이 안전하다.
2. 4~6학년 학생 3명 이상에게 첫 화면과 각 미션을 3초 보여 준 뒤 “지금 무엇을 해야 해?”, “어디를 눌러야 해?”를 묻고, 막힌 화면과 첫 클릭 위치를 기록한다.
3. 성취기준 코드·문구를 교육과정 원문과 대조하고, 공개 URL이 생기면 시작→브리핑→저장→새로고침→이어하기 smoke test를 실행한다.
