연결 범위에는 한계가 있다. P9의 기존 세 작전·네 직업 릴레이는 `Page08Crisis.tsx:177`의 미션별 고정 정답 판정을 유지한다. 개인 기록을 직접 읽는 부분은 마지막 `TransferMission.tsx:33`의 생태 기록 비교다. 모든 릴레이 턴이 각 학생의 사진·돌봄·방송 산출물을 판정 입력으로 사용하도록 바뀐 것은 아니다. 이 네 역할 전체의 개인화는 11점 고도화의 남은 조건이며, 현재 구현보다 넓게 성과를 적지 않는다.
