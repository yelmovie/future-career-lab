## 이전 결함과 개선

- 비교 그림이 모두 실패하면 안내·다시 시도·숫자로 확인하기가 나타난다. 확인 전에는 완료되지 않고, 새로고침·재연결에도 세 비교 기록을 중복 저장하지 않는다.
- 본문 바로가기는 해시 주소를 바꾸지 않는다. 확대 사진의 실제 관찰 지점을 키보드로 찾고 가설까지 완료할 수 있다. 모달의 초점 유지·복원과 단계별 미완료 안내도 보완했다.
- 방송 선택 버튼은 짧은 제목만 담고, 실제 자막은 버튼 바깥 설명으로 읽는다. 선택한 자막과 조사 수치는 방송 다시보기에 이어진다. 마이크 복구 장면, 선택형 조사자료와 자동 방송 재생은 유지한다.
- 방송을 완성하면 배지 카드를 먼저 보여 주고 학생이 `내 방송 이어 보기`를 눌러 재생으로 넘어간다. 배지 지급·화면 표시·예전 저장 기록을 모두 자동 검사했다.
- 공사 소리를 비교하고 가림벽·기계 휴식 중 실제 부탁을 고른다. 부탁에 따라 결과 설명과 탐험 기록이 달라진다.
- 학교 화단은 선택형 후일담이다. 숲에서 효과가 컸던 나무를 무조건 반복하지 않고 빈 물그릇을 관찰한다. 도움을 다시 고르고 길게 누르기/짧게 누르기로 물을 채운다. 새 장소의 그림 두 장을 생성했고 수정·중간 진행을 저장한다. 이 활동을 하지 않아도 수료증을 받을 수 있다.
- 후반 PNG 13개는 동일 해상도·투명도의 WebP로 줄였다. 원본과 변환 해시를 보관했다. 자동 자료 준비는 실제 파일 수를 표시하고 중단 시 남은 파일부터 이어 받는다.
- 삭제한 원자료 강제 열기, 연구기록 시험, 방송 잠깐 멈추기, 설정의 준비·정답 판정 안내는 복구하지 않았다. 선택한 OG 3번과 16job 주소를 유지한다.

## 남은 현장 확인

실제 초등학생의 난이도·재미·완주 동기, 교실 뒷자리 가독성, 물리 태블릿의 터치·스피커, 학교망 동시 접속은 개발 브라우저 검사로 통과 처리하지 않는다. 일부 외부 음성·3D 에셋의 생성 당시 계정 플랜·계약 증빙도 문서만으로 확인할 수 없어 미확인으로 남긴다.

코드는 앞으로도 더 나눌 수 있다. 협업·학교 화단 내용은 JSON으로 분리했지만 큰 기존 화면과 일부 UI 문자열은 코드에 남아 있다. 모든 내용을 교사가 무코드 편집할 수 있는 도구로 소개하지 않는다.
