# 화면 피드백과 공사 음원 반영

2026-09-11~12 사용자 화면 피드백을 반영한 기록이다. 이전 스테이지 5 구조 개편 위에 적용했다.

## 적용

1. 공사장에 CC0 실제 장비 녹음 12초 루프와 ‘공사 소리 듣기/멈추기’를 연결했다. 슬라이더와 실제 음량이 함께 변하고, 0에서는 무음이다. 듣기는 선택이며 전체 음소거·효과음 0·화면 이동을 존중한다. 실패 안내와 재시도가 있다. 출처·가공·해시는 `docs/STAGE5-CONSTRUCTION-AUDIO.md`와 `assets/licenses/construction-audio.json`에 기록했다.
2. 마지막 숲 비교는 **왼쪽 이전 모습 / 오른쪽 함께 바꾼 모습**으로 고쳤다. 처음에는 절반씩 보여 주며, 그림 위에 각각의 제목을 붙였다. 하단은 ‘두 모습 비교하기’로 바꿔 슬라이더 양 끝의 의미와 좌우 그림 제목을 혼동하지 않게 했다.
3. 수료증에서 ‘지구와 젤리를 찾고’를 제거했다. 도입·직업 목록·협력·수여 문장의 4줄을 화면·PNG·인쇄에서 공유한다.
4. 드론 지도의 큰 바람 구역 사각형과 반복 화살표를 없앴다. 바람 안내를 지도 위쪽에 따로 두고, 파란 이동선과 청록 점선 복귀선에 실제 진행 방향을 표시한다. 정찰과 4초 다시 보기 모두 마지막 지점에서 이륙장까지 이어진다.
5. 방송 다시 보기의 ‘잠깐 멈추기’ 버튼·상태·대화·도움말 안내를 제거했다. 자동 재생과 이전/다음, 마지막의 처음부터 다시 보기는 유지한다.
6. 증거판 배지 팝업은 ‘단서로’ 및 ‘찾았대!’ 뒤를 나눠 3줄로 맞췄다. 다른 배지 문구에는 줄 수를 강제하지 않았다.

## 검증

- 전체 단위: **20파일 179개 PASS**.
- 전체 ESLint PASS. 실행 중 잠길 수 있는 생성 결과 폴더 `artifacts/drone-route-test-results`만 기존 검사 제외 목록에 추가했다.
- 공사 음원: 브라우저 5개 시나리오 검증. 실제 HTMLAudio 재생시간 증가·loop, Web Audio gain 감소·무음, 음소거 해제 후 자동재생 없음, 지도·결과 이동 정리, 듣기 없이 완료, 태블릿 hasTouch 탭을 확인했다. 최초 4개 및 추가/보강 2개를 나눠 실행했다.
- 협업 흐름 4개와 전역 화면 경계 2개: **6 PASS**. 1024×768 및 1728×972에서 주요 화면과 긴 문구 상태의 상단·중앙·말풍선 경계를 확인했다. 결과 폴더 `test-results/cooperation-layout-followup`.
- 방송·수료증·증거판 관련 브라우저 **4 PASS**. 실제 수료증 PNG와 인쇄 보기, 두 해상도 화면을 `artifacts/copy-layout-20260912/`에 보관했다.
- 드론: 경로 모델 4개 단위 검사, 1024/1280 경로점 드래그·3곳 촬영·실제 복귀·다시 보기 흐름을 확인했다. 그림 `artifacts/drone-route-{1024,1280}-{plan,return,review}.png`.
- 비교 지도 0/50/100 상태: `test-results/current-ui/comparison-{0,50,100}.png`.
- 자산 manifest: **260개 미디어 / 146개 실행 자원 PASS**. 새 음원도 배포·오프라인 준비 목록에 포함된다.
- 최종 TypeScript + Vite 빌드 PASS. 무결성 검사 **183파일 / 89,527,403바이트**. `dist/audio/v9/construction-site-loop.wav` 포함.

브라우저의 태블릿 에뮬레이션 결과이며 실제 학생·학교 기기의 현장 검증을 의미하지 않는다. 원격 배포와 커밋은 하지 않았다.

## 추가 설정 정리

사용자 표시대로 교사용 가이드의 수업 자료 준비 UI, 정답지·판정 기준, 운영 준비, 성취기준 설명 서문과 연계표를 삭제했다. 성취기준 4항목은 처음부터 펼쳐 보인다. 기존 교사용 해금/종료 및 전체 화면 이동 기능은 유지했다. 학생용 가이드에서는 ‘왜 네 직업이나 해?’ 단락을 제거했다. 사용하지 않는 정답 데이터·연계표·스타일과 수업 준비 컴포넌트 import도 제거했다. 기존 저장 기록과 음량 조작에는 영향을 주지 않는다.

설정 정리 후 교사용 전체 화면 이동·성취기준 표시·삭제 항목 부재·학생 기록 불변 E2E 1개 PASS, 전체 ESLint와 TypeScript/Vite build PASS. 최종 무결성 검사는 **185파일 / 89,513,191바이트**다. `artifacts/settings-cleanup-20260912/{teacher,student}.png`에서 태블릿 화면을 확인했다. 공사 음원의 CC0 크레딧도 설정 정보에 추가했다.
