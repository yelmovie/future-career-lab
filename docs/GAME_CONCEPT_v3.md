# 미래 직업실 v3 — 스토리 바이블 「사라진 꾸꾸와 앵자」

작성일: 2026-09-05 · 상태: **채택** · 대상: 초등 5~6학년 · 메커닉은 v2 그대로, **서사와 문구만 교체**

## 1. 한 줄 콘셉트

> 동물원 새 정원에서 도망친 앵무새 두 마리를 찾는 작은 사건이, 네 직업이 힘을 모아 도시 옆 숲의 새들을 지키는 큰 일로 자란다.

메인 메시지: **직업은 혼자 일하지 않는다. 사건 하나에 네 직업이 이어 붙고, 마지막엔 넷이 동시에 움직여야 풀린다. 미래에는 이런 협력이 더 중요해진다.**

## 2. 후보 3안과 선택

| 안 | 줄거리 | 문제 |
|---|---|---|
| A. 숲 앵무 감소(v2) | 숲에서 야생 앵무가 줄어든다 | 우리나라 숲에 야생 앵무 무리는 없다. 억지 설정 |
| B. 사용자 안 | 사육사가 앵무 두 마리를 잃음 → 드론 수색 → 방송으로 시민 도움 → 생태연구가가 발견하며 새 서식지 감소 발견 | 방송이 생태보다 앞서면 S4 메커닉(그래프 자막)이 재료를 못 받는다 |
| **C. 채택 (B 보정)** | 사육사가 두 마리를 잃음 → **드론**으로 넓은 숲 수색·단서 → 깊은 숲에서 발견·**구조·돌봄** → 사육사의 질문 "왜 숲 가장자리엔 새가 없지?"를 **생태연구가**가 조사 → **방송**으로 시민에게 정확히 알리고 도움 요청 → 태풍·화재·소문 위기를 **네 직업 연합**으로 해결 | 페이지 순서·코드 변경 0. 작은 사건→큰 문제로 커지는 구조가 "협력의 필요"를 자연히 보여 준다 |

B의 "시민 도움"은 S4 세그먼트 '시민 행동 안내'와 S5 위기 3(시민 오해)에 그대로 들어간다.

## 4. 스테이지별 서사 (메커닉은 그대로)

### P1 HOME
- 소제목: **네 직업이 힘을 모아 사라진 앵무새를 찾아라**
- 미션 칩: `MISSION · 사라진 꾸꾸와 앵자를 찾아라`
- 말풍선 학생: "꾸꾸랑 앵자가 숲으로 날아갔대. 어디서부터 찾지?" / 멘토: "혼자 말고 넷이 함께. 직업마다 보는 눈이 달라."

### P2 브리핑 (사건 접수)
대사 3줄:
1. "하늘숲 동물원 새 정원 그물이 태풍에 찢어져서, 앵무새 꾸꾸와 앵자가 푸른솔 숲으로 날아갔어. 사육사 혼자선 넓은 숲을 다 뒤질 수 없어."
2. "한 직업만으로는 못 찾아. 하늘에서 보고, 살피고, 조사하고, 알리는 네 사람이 필요해."
3. "네가 네 직업을 차례로 맡아 봐. 마지막엔 넷을 한 팀으로 묶어야 풀리는 일이 기다리고 있어."
- 끝내면 얻는 것: "…그리고 꾸꾸와 앵자가 새 정원으로 건강하게 돌아가."
- 키아트 alt: 저녁 하늘, 숲 쪽으로 날아가는 초록·빨강 앵무 두 마리와 멀리 보이는 공사장

### S1-a 드론 정찰 (P3)
- 왜 드론: 숲이 넓어 사람이 걸어 찾기엔 너무 크다. 위에서 봐야 앵무가 갈 만한 곳·피할 곳이 보인다.
- 촬영 목표 3곳 이름 유지(벌목지 · 막힌 물길 · 공사장). 미션 문구: "꾸꾸와 앵자가 갈 만한 곳 3곳을 드론으로 찍어"
- 사진 카드 설명은 "앵무가 먹이·물·조용한 곳을 찾아 어디로 갔을지"의 단서로 읽힌다.

### S1-b 증거판 (P4)
- 질문: **"꾸꾸와 앵자는 왜 숲 가장자리를 떠났을까?"** (가설 3택 유지)
  - 벌목 때문: 열매 나무가 잘려 먹이가 없어 더 깊은 숲으로 갔을 거야
  - 소음 때문: 공사 소리에 놀라 조용한 곳으로 갔을 거야
  - 물 때문: 물길이 막혀 물 있는 곳을 찾아갔을 거야
- 사실 카드: CCTV(밤마다 트럭이 숲길로) / 발자국(부츠 자국이 물가까지) / 녹음기 기록: **"새소리가 일주일 전부터 숲 가장자리에서 안 들려"** / 도시 야경(무관)
- 완료 띠: "가설을 세웠어. 사육사가 깊은 숲 열매 나무 근처에서 두 마리를 찾았대! 상태가 안 좋아 — 살피러 가자."

### S2-a 건강 점검 (P5)
- 제목: **구조된 꾸꾸와 앵자 살피기**
- 초록 = 꾸꾸(스트레스, 깃털 뽑음), 빨강 = 앵자(탈수). 이름으로 부른다.
- 멘토 = 사육사 하늘: "둘 다 힘들어 보이지만 이유가 달라. 같은 처치를 하면 한 마리는 더 나빠져."

### S2-b 회복 공간 (P6)
- 제목: **새 정원 다시 만들기** — 찢어진 새 정원을 두 마리 상태에 맞게 다시 꾸민다(회복 + 다시 도망가지 않게).
- 완료: "꾸꾸와 앵자가 새 정원에서 쉬고 있어. 그런데 사육사가 물었어: '숲 가장자리엔 왜 새소리가 없었지?'"

### S3 생태 조사 (P7)
- 왜 생태연구가: 두 마리는 찾았지만 **숲 가장자리에서 새가 사라진 이유**는 모른다. 흔적을 모으고 조건을 하나씩 바꿔 확인한다.
- 흔적: 초록 깃털/빨강 깃털 = **꾸꾸·앵자가 지나간 길**, 앵무 발자국·울음 = 꾸꾸·앵자가 머문 흔적, 부츠·전기톱·고양이 = 위험 단서.
- 태블릿 그래프·실험의 "앵무 개체수" → **"숲의 새 개체수"**(모든 새). 지점별 "앵무 흔적 수" → "새 흔적 수".
- 모델 고지 문구 유지("실제 숲은 더 복잡해요…").
- 완료: "주원인을 찾았어. 이건 꾸꾸·앵자만의 일이 아니야 — 숲의 새들이 줄고 있어. 시민에게 알려야 해."

### S4 생방송 (P8)
- 왜 방송: 원인을 알았으니 **정확하게** 알리고 시민의 도움을 얻는다.
- 세그먼트: 오프닝(꾸꾸·앵자 구조 소식과 숲 문제 소개) / 현장 상황(드론 사진) / 원인 설명(그래프) / 전문가 인터뷰(사육사·생태연구가) / 시민 행동 안내(**시민 도움 요청**) / 클로징
- 자막 텍스트의 "앵무새" → "숲의 새". 소문 카드: "숲의 새들이 다 도시로 갔대요"(SNS) / "고양이가 새를 다 잡아먹었어요" / "새는 곧 저절로 돌아와요" / "숲 가장자리 나무가 작년보다 줄었어요"(익명)
- 잘못된 제보: "'앵무새가 학교에 나타났다'" → "'또 다른 앵무새가 학교에 나타났다'는 제보" (꾸꾸·앵자는 이미 구조됨)
- 행동 카드: "다친 새를 보면 동물원 돌봄센터에 알려 주세요" / "숲 가장자리 공사 소음을 줄여 주세요"

### S5 연합 작전 (P9)
방송 다음 날 위기 3개가 동시에 온다.
1. **숲 가장자리 화재** — 공사장 불꽃이 벌목지 마른 가지로 번짐. 어디까지 퍼졌는지 모르고 시민도 모른다 → 드론 + 방송
2. **새 둥지 구역 대피** — 태풍이 다시 온다는 예보. 새들이 어디로 이동할지 알아야 하고, 다친 새를 받을 곳이 없다 → 생태 + 돌봄
3. **시민 오해** — "새 때문에 공사가 멈췄다"는 소문. 진짜 원인을 근거로 알려야 한다 → 방송 + 생태
- 엔딩: 불 꺼지고 숲 노드 초록, 새 정원에서 꾸꾸·앵자 건강, 숲에 새소리 돌아옴, 시민 숲 지킴이 참여. 연합 엠블럼.
- 엔딩 문구: "혼자였다면 하나도 못 막았어. 넷이 이어 붙어서 셋을 다 지켰어."

### P10 돌아보기 · P11 수료증
- 예측 vs 실제 6축 유지. 생활 전이 상황 카드: "우리 학교 옆 공원 공사로 새가 안 온다면?" 네 직업 순서 배열.
- 능력 문장 6개 유지, 마지막 항목 강조: "여러 직업이 차례로 힘을 보태 문제를 풀 수 있다" (2026-09-08 릴레이 재설계에 맞춰 문구 교체).
- 수료증 본문에 한 줄 추가: "꾸꾸와 앵자를 찾고 푸른솔 숲의 새들을 지키는 데 네 직업의 힘을 모았습니다."

## 5. 학습목표 ↔ 행동 (변경 없음, 메시지만 강화)

| 목표 | 스테이지 | 이 서사에서 이유 |
|---|---|---|
| 직업은 이름이 아니라 판단 방식 | 전체 | 같은 사건을 네 직업이 다른 도구로 본다 |
| 제약 속 계획 | S1 | 넓은 숲, 배터리·바람 |
| 근거로 추론 | S1-b·S3 | 어디로 갔나 / 왜 사라졌나 |
| 개체별 돌봄 | S2 | 꾸꾸·앵자의 이유가 다르다 |
| 변인 통제 | S3 | 새가 줄어든 진짜 원인 |
| 정보 출처 판단 | S4 | 시민 도움을 얻으려면 정확해야 한다 |
| **협업 = 역할의 조합, 미래엔 더 중요** | S5·P10 | 위기 셋이 동시에 오면 한 직업으론 못 막는다 |

## 6. `[가정]` · `[검증 필요]`

- [가정] 이클렉투스 앵무는 동물원·가정 사육 개체이며 우리나라 숲에 야생 무리는 없다. 숲의 "새"는 특정 종을 지정하지 않는다.
- [가정] 태풍으로 아비어리 그물이 찢어지는 사건은 허구다.
- [검증 필요] 탈출한 앵무가 가을 우리나라 숲에서 며칠 생존 가능한지 — 게임에서는 "발견 시 상태가 안 좋다"로만 다룬다.
- [검증 필요] 2022 개정 진로 성취기준 코드(기존 문서 그대로).

## 7. 자기비평

- 강점: 작은 사건→큰 문제로 자라 협력의 필요가 설명이 아니라 사건으로 드러난다 / 코드 변경 0 / 꾸꾸·앵자라는 이름이 생겨 감정 이입이 쉽다.
- 약점: S3에서 "앵무 흔적"을 "새 흔적"으로 바꾸면 깃털 단서 의미가 흐려질 수 있다 → 깃털은 꾸꾸·앵자 흔적으로 명시 / S5 화재는 여전히 극적이다(초등 5~6 허용 범위).
- 반드시: 모든 화면에서 이름·지명 표기를 §3 표로 통일한다.

> **진짜 게임 행동 한 문장:** "직업마다 다른 도구로 꾸꾸와 앵자를 찾다가, 숲의 새들을 지키려면 네 직업이 동시에 움직여야 한다는 걸 몸으로 안다."
