## 추가·교체 절차

1. 현재 스테이지 폴더에 에셋을 넣고 코드 참조를 연결한다.
2. `node scripts/validate-assets.mjs --write`로 해시·참조 목록을 갱신한다.
3. `npm run verify`로 참조 누락·GLB 구조·테스트·빌드를 검사한다.
4. `node scripts/verify-classroom-release.mjs dist`로 실제 배포 파일 무결성을 확인한다.
5. 에셋 교체 후 크레딧과 관련 라이선스 기록을 `docs/`에서 갱신한다.

참조 수집기는 동적 파일명 패턴도 사용한다. 새 패턴을 추가하면 실제 사용 파일과 대체 이미지가 모두 인벤토리에 포함되는지 확인한다. 로컬 보관 폴더의 원본은 자동 삭제하지 않는다.
