# 프로젝트 이미지 생성 기준

새 이미지를 만들기 전에 `public/assets/page-01/keyart.webp`, 해당 스테이지의 멘토·배경·대표 소품을 직접 확인한다. 확인한 프로젝트 에셋을 이미지 생성의 스타일 레퍼런스로 넣고 아래 기준을 고정한다.

- 기본 화풍: 어린이용 프리미엄 3D 교육게임 일러스트
- 인물: 큰 눈, 둥글고 친근한 얼굴, 단순하고 매끈한 피부·머리카락, 또렷한 실루엣
- 동물: 종의 특징은 유지하되 큰 눈과 둥근 비율, 층이 단순한 조형 깃털, 사진 같은 미세 깃털 금지
- 공간·장비: 둥근 모서리, 장난감처럼 정돈된 3D 재질, 네이비·코발트·시안에 따뜻한 골드와 코랄 포인트
- 조명: 밝고 따뜻한 시네마틱 조명, 어린이 화면에 맞는 높은 가독성
- 금지: 프로젝트 확인 없이 포토리얼·실사 인물·실사 방송실·일반 스톡 이미지 화풍으로 생성

예외는 자연 관찰 자체가 학습 자료인 장면이다. 사용자가 실사 또는 준실사를 유지하라고 한 숲·물길·드론 현장 장면은 그대로 두고, 사람·실내 공간·장비·동물 아이콘만 프로젝트 화풍에 맞춘다.
