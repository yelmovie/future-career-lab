# 미래 직업실 v2 — 고도화 설계

작성일: 2026-09-04 · 상태: **제안 (승인 대기)** · 선행 문서: [GAME_CONCEPT_v2.md](GAME_CONCEPT_v2.md)
이 문서는 콘셉트를 final-check 23항목 기준으로 다시 훑어 **스테이지별 상호작용·긴장·보상·재도전**을 확정한 버전이다. 코드는 아직 없다.

---

## 0. 콘셉트 요약 (변경 없음)

숲의 앵무새가 사라진 사건을 드론 현장가 → 동물돌봄 → 생태연구가 → 방송기술자 순으로 조사하고, 마지막에 네 직업을 합쳐 해결한다. 앞 스테이지 산출물(사진·기록·그래프·클립)이 뒤 스테이지 재료다.

## 1. final-check 23항목 대조 — 설계에서 미리 막을 것

점수는 매기지 않는다(구현 전). 설계로 결정되는 항목만 골라 **v2에서 무엇을 바꿨는지** 적는다.

## 2. 스테이지 매트릭스 (23번 필수 산출물)

| 스테이지 | 주 조작 | 상호작용 종류 (≥3) | 긴장 장치 | 즉시 보상 | 재도전 이유 (갱신 목표) |
|---|---|---|---|---|---|
| 소개 P2 | 카드 뒤집기 | 탭·입력·선택 | 없음 (의도적, 진입 화면) | 명찰 | – |
| S1-a 드론 | **경로 드래그** | 드래그·관찰(바람)·타이밍(REC 탭)·리플레이 | 배터리 게이지 vs 바람 | 사진 3장 카드화 | 배터리 30% 이상 남기고 3컷 = "정밀 비행" 도장 |
| S1-b 증거판 | **선잇기** | 선잇기·확대 관찰(사진 속 세부 찾기)·3칸 분류(확실/의심/무관) | 잘못된 연결은 선이 떨리며 "어느 사진이 뒷받침해?" | 가설 카드 | 다른 가설로 S3 재검증 |
| S2-a 건강 점검 | **관찰·기록** | 회전/줌 관찰·체크리스트 분류·소리 듣기·개체별 처치 매칭 | 두 마리 상태가 달라 같은 처치는 한 마리 악화 | 개체 상태 게이지 즉시 반응 | 두 마리 모두 "안정" 도달 |
| S2-b 서식지 | **배치·시뮬** | 드래그·회전·스냅·시뮬 관찰·재설계 | 시뮬 결과가 예측과 다름 | 앵무 행동 변화 | 만족도 3별 |
| S3 생태 조사 | **변인 통제** | 핫스팟 탐색·소리 분류·그래프 비교·슬라이더(1개씩)·예측 입력 | 예측 먼저 입력 → 실행 → 대조 | 개체수 즉시 반응, 흔적 도감 스탬프 | 도감 8칸 채우기 (숨은 흔적 2개) |
| S4 방송 | **큐시트 판단** | 소스 탭·자막 드래그·오디오 레벨 슬라이더·사고 우선순위(AP)·큐 타이밍 | 시청자 신뢰 게이지, 세그먼트마다 조건 | 송출 화면 즉시 반영 | 정정 0회 "클린 방송" |
| S5 연합 | **시너지 배치** | 배지 드래그·카드 선택·턴 순서 결정·확산 관찰 | 턴마다 위기 확산, 잘못된 짝은 무효 | 위기 게이지 감소·노드 복구 | 최소 턴 클리어, 카드 품질 갱신 |
| 결과 P10 | 문장 고르기 | 선택·비교·짧은 입력 | 없음 | 능력 문장 → 수료증 | 예측 다시 하기 |

X 칸 없음. 시간제한 없음. 가장 약한 스테이지 후보는 S2-b(기존 코드 그대로)라 "만족도 3별 + 개체 조건 연동"으로 보강했다.

## 3. 스테이지 상세 (변경분 중심)

### 소개 · P2 탐험단 브리핑
- 회의 테이블(bg2). 멘토 대사 3줄: 사건 / 네 직업이 필요 / 마지막에 합친다.
- **보상 예고 고정 문구**: "끝내면 배지 5개, 수료증, 그리고 앵무새가 숲으로 돌아가."
- 4직업 카드 뒤집기 → 도구 3개씩 노출. 학생: 이름 + "제일 잘 맞을 것 같은 직업" 1개 예측.
- 미션 카드 규격(전 스테이지 공통, 22번 ②): `이번 미션 / 끝내면 얻는 것 / 배우는 것 한 줄`.

### S1-a 드론 정찰 (P3)
- 바람 3구간 랜덤(seed). 맞바람 배터리 2배.
- **추가**: 비행 중 촬영 목표 위에서 REC 탭(타이밍). 놓치면 한 바퀴 더 돌아야 해 배터리 소모 → 계획의 중요성 체감.
- 사진 3장은 신규 에셋 `v2.photo.*` (fallback: 배경 크롭). 저장 `artifacts.photos[]`에 촬영 품질(정중앙/가장자리) 기록.
- 실패: 배터리 0 → 자동 귀환, "어느 구간에서 빨리 닳았지?" + 바람 화살표 강조.

### S1-b 증거판 (P4)
- 증거판 위: 내 사진 3장 + CCTV 클립 + 발자국 단서.
- **추가 ① 확대 관찰**: 사진을 탭하면 확대, 숨은 세부(그루터기 톱 자국 / 물길 막은 자재 / 공사 소음 표지) 핫스팟 찾기. 찾은 세부만 연결 재료가 된다 → 사진을 안 보고는 연결 불가.
- **추가 ② 3칸 분류**: 단서 카드를 확실/의심/무관으로 드래그. "무관" 카드 1장 섞여 있음(도시 야경).
- 유효 연결 2개 → 가설 3택. 정답 고정 없음. S3에서 검증.

### S2-a 건강 점검 (P5)
- 초록: 스트레스(깃털 뽑음·소리 날카로움), 빨강: 탈수(눈 흐림·물 안 마심). 
- **추가 소리 듣기**: 각 개체 탭 → 울음 재생(신규 SFX, fallback 없으면 파형 아이콘만). 정상/이상 분류.
- 처치 카드 4장을 개체별로 매칭. 같은 카드 둘 다 → 한 개체 게이지 하락 + "물을 줬는데 안 마셔. 왜일까?"
- BGM 덕킹 적용.

### S2-b 회복 서식지 (P6)
- 기존 배치·시뮬 유지. **조건 연동**: 탈수 개체는 물까지 거리, 스트레스 개체는 은신처 필수. 조건은 S2-a 기록에서 자동 생성.
- 만족도 3별(행동 관찰 결과: 먹기/놀기/쉬기 3개 다 관찰되면 3별).

### S3 숲 생태 조사 (P7, 신규)
1. **흔적 수집**: bg6 정글에서 지점 A·B·C 이동(좌우 스와이프). 핫스팟 8개: 발자국 3종(앵무/고양이/부츠), 깃털 2, 소리 3(앵무 정상/앵무 경계/전기톱). 소리는 녹음기 탭 → 재생 → 3택 분류. 도감 스탬프.
2. **연구 태블릿**: 지점별 막대 4개(먹이나무·소음·물·앵무 흔적). 학생이 "흔적 적은 지점에서 튀는 값"을 스스로 고른다. 정답 표시 없음, 고른 것이 3단계 첫 실험 변수가 됨.
3. **변인 실험**: 슬라이더 3개, **한 번에 하나만 활성**. 순서: 예측(개체수 ↑/↓/같음) 입력 → 실행 → 즉시 결과 → 대조. 3회 후 주원인·보조원인 확정.
- 모델 `[가정]` 교육용 단순 함수. 화면 하단 고정 문구: "실제 숲은 더 복잡해요. 이 실험은 '하나씩 바꿔 보기'를 연습하는 거예요."
- 산출: 그래프 카드 3장(`artifacts.graphs[]`), 원인 판정.

### S4 생방송 컨트롤룸 (P8, 신규) — 타이머 없음
- **큐시트 6세그먼트** 턴제: 오프닝 / 현장 상황 / 원인 설명 / 전문가 인터뷰 / 시민 행동 안내 / 클로징.
- 세그먼트마다 3가지 결정:
  1. 소스 선택(드론 사진 / 스튜디오 / 현장 리포터) — 세그먼트 요구와 맞아야 함.
  2. 자막 드래그 — 근거 카드(S3 그래프 3장 + S1 사진 캡션 3장) vs 출처 없는 카드 3장. 출처 없는 카드 송출 → 신뢰 하락 + 다음 세그먼트 하나가 "정정 방송"으로 강제 소비.
  3. 오디오 레벨 슬라이더 — 파형이 빨간 구간(클리핑) 안 닿게. CSS 파형.
- 돌발 사고 2회(마이크 끊김/영상 지연/잘못된 제보): AP 3 배분(기존 Page07 모델).
- 결과: 신뢰 게이지 + 방송 클립 카드(`artifacts.clip`). 일시정지 자유.

### S5 연합 작전 (P9) — 턴제
- 위기 3개, 턴마다 확산. 위기 카드에는 **능력 힌트만** ("위에서 봐야 해", "근거가 필요해", "보호할 곳이 필요해"), 배지 이름 없음.
- 배지 4개 드래그 + 카드 선택. 카드 품질(S1 촬영 정중앙 / S3 주원인 정답 / S4 신뢰도)이 효과량. 
- 잘못된 짝 → 무효 + "이 위기엔 무엇이 필요하다고 써 있지?"
- 엔딩: 화재 소멸 → 숲 노드 초록 → 앵무 무리 귀환(신규 장면 `v2.scene.restored`, fallback bg6+앵무 쌍) → 연합 엠블럼.

### 결과 · P10 돌아보기 / P11 수료증
- P2 예측 vs 실제 6축 성향. 근거 3개는 실제 로그.
- **생활 전이(22-⑤)**: "우리 학교 근처에서 이런 일이 생기면?" 상황 카드 1장(예: 놀이터 옆 공사로 새가 안 옴) → 네 직업 중 누가 먼저 무엇을 하면 좋을지 순서 배열. 정답 아닌 "내 계획".
- **능력 진술(22-11점)**: "나는 이제 ___ 할 수 있다" 문장을 5개 후보 중 2개 고르거나 직접 씀 → 수료증에 인쇄.

## 5. 학습목표 ↔ 행동 (추가분)

| 목표 | 행동 | 스테이지 |
|---|---|---|
| 관찰 없이는 판단할 수 없다 | 사진 확대해 세부를 찾아야 연결 가능 | S1-b |
| 개체마다 처치가 다르다 | 같은 처치 → 한 마리 악화 | S2-a |
| 변인 통제 | 슬라이더 하나만 활성 + 예측 먼저 | S3 |
| 정보 출처 판단 | 출처 없는 자막 → 정정 비용 | S4 |
| 협업 = 역할 조합 | 능력 힌트로 짝 찾기 | S5 |
| 생활 전이 | 학교 근처 상황에 직업 순서 배열 | P10 |
